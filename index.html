The tunnel makes this service reachable from the Internet. Use the service’s login or a Cloudflare Access policy. HTTPS for *.local.chancecox.com needs matching Cloudflare certificate coverage.

Both modes can be enabled using different hostnames. Turning a mode off removes its HomeScan-managed DNS record and tunnel route.

Connect Cloudflare

1. Sign in and create your token

Log in & create token ↗

Opens Cloudflare in a new tab. Sign in, then choose Create Token → Create Custom Token. Name it HomeScan and add these permissions:

  • Zone → Zone → Read
  • Zone → DNS → Edit
  • Account → Cloudflare Tunnel → Edit for tunnels

Limit Zone Resources to chancecox.com and Account Resources to the account that owns it. Select Continue to summary → Create Token, then copy the token.

2. Connect HomeScan

Run this command on the HomeScan PC and paste the token into its hidden prompt. It connects the account and starts a dedicated HomeScan tunnel.

powershell -NoProfile -ExecutionPolicy Bypass -File C:\homeScan\configure-cloudflare.ps1

Use -LocalDnsOnly with the command if you only want local DNS. Settings can be saved before connecting; they’ll be applied when credentials are ready.

For tunnel URLs below local.chancecox.com, configure a certificate covering *.local.chancecox.com, for example with Advanced Certificate Manager / Total TLS.
