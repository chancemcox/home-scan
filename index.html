Connect Cloudflare

1. Sign in and create your token

Log in & create token ↗

Opens Cloudflare in a new tab. Sign in, then choose Create Token → Create Custom Token. Name it HomeScan and add these permissions:

  • Zone → Zone → Read
  • Zone → DNS → Edit
  • Account → Cloudflare Tunnel → Edit for tunnels

Under Zone Resources, choose Include → All zones from an account (do not pick individual zones — that hides the rest of your domains from HomeScan). Select Continue to summary → Create Token, then copy the token.

2. Save the token in HomeScan

The token is stored only on this HomeScan host and is never shown again.

Public hostnames

Edit the origin host and port the connector reaches, or delete a hostname. Add another hostname to the same computer with Add hostname.

The last ingress rule must be a catch-all. HomeScan-managed device routes must be changed from the device inventory.

Automatic origin IP

Link an ingress rule to a computer. HomeScan will follow its MAC address and replace the origin IP after every scan while preserving the service protocol and port. The same computer can own multiple hostnames.
